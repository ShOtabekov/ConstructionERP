# Офлайн-установщик «Строительная ERP»

Один файл `StroyERP-Setup-<версия>.exe` (~0,7 ГБ) ставит у клиента всё без интернета:
Python, Odoo 19, наши модули, PostgreSQL 16, wkhtmltopdf (печать PDF), службу Windows,
ярлык на рабочем столе, ежедневную резервную копию в 19:00.

Требования к компьютеру клиента: Windows 10/11 64-бит, 4 ГБ ОЗУ, 5 ГБ на диске C:.

## 1. Сборка (один раз, у вас в офисе, нужен интернет)

```
cd C:\Projects\Construction-ERP-New\installer
powershell -ExecutionPolicy Bypass -File build.ps1 -Version 1.0
```

Скрипт сам скачает компоненты в `installer\downloads` (повторно не качает), поставит Inno Setup,
установит библиотеки в отдельный Python и соберёт `installer\output\StroyERP-Setup-1.0.exe`.
Если какая-то ссылка устарела — скрипт скажет, какой файл скачать вручную и куда положить.

Перед сборкой новой версии: `git pull` (берутся текущие `odoo\` и `custom_addons\`).

## 2. Установка у клиента (интернет не нужен)

1. Скопировать `StroyERP-Setup-1.0.exe` с флешки, запустить от администратора.
2. Ввести название компании и пароль директора (логин — `admin`).
3. Подождать 5–15 минут — откроется окно входа в браузере.

Ставится в `C:\StroyERP`: `pgdata` — база, `data` — файлы, `backups` — копии, `logs` — журналы.
Порты: Odoo 8069, PostgreSQL 5433 (свой экземпляр, другие программы не трогает).

## 3. Обновление у клиента

Запустить установщик новой версии поверх старой: файлы заменятся, база обновится
(модули обновляются при установке), данные сохранятся. Перед этим сделать резервную копию.

## 4. Если установка не прошла

Журнал: `C:\StroyERP\logs\install.log` и `odoo.log` — пришлите разработчику.
Повторный запуск установщика безопасен: готовые шаги пропускаются.
