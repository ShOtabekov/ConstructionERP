СТРОИТЕЛЬНАЯ ERP — краткая памятка
==================================

Вход в систему
  Ярлык «Строительная ERP» на рабочем столе (открывается в браузере).
  Логин: admin
  Пароль: тот, что ввели при установке.
  Интернет не нужен. Система запускается сама вместе с Windows.

С чего начать
  1. Проекты → Новый: название ЖК, курс USD/TJS.
  2. Проект → вкладка «Реквизиты для договоров»: продавец, руководитель, адрес.
  3. Недвижимость → Создать блок (или шаблон Rahmoniyon).
  4. Недвижимость → Прайс-лист: цены за м².
  5. Шахматка → выбрать квартиру → «Продать».

Резервные копии
  Каждый день в 19:00 копия сохраняется в папку C:\StroyERP\backups (хранятся 30 последних).
  Вручную: Пуск → Строительная ERP → «Сделать резервную копию».
  РЕГУЛЯРНО копируйте эту папку на флешку!
  Восстановить: Пуск → Строительная ERP → «Восстановить из копии».

Если что-то не работает
  Перезагрузите компьютер. Если не помогло — отправьте разработчику файлы
  из папки C:\StroyERP\logs.
