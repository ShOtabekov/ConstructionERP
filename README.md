# Construction ERP

An offline-first Construction ERP system for construction companies and real estate management in Tajikistan.

## Technology Stack

- Odoo 19 Community
- Python
- PostgreSQL
- XML
- JavaScript

## Current Features

- Construction project management
- Building management
- Entrance management
- Floor management
- Apartment management
- Project structure and relationships

## Installation

1. Install Odoo 19 Community.
2. Clone this repository.
3. Copy `custom_addons` into your Odoo addons directory.
4. Add the custom addons directory to `addons_path`.
5. Restart Odoo.
6. Install `construction_core` from the Apps menu.
